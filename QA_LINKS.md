## When to publish a test run
- Certifying a build for release
- Sharing a bug report among the team

## How to publish a test run
- Create a /run/xxx branch in the repo to store the results of your test run
- Edit individual .md files with results, notes, etc.
- Commit those edits to the /run branch you created
- See [How to Publish Test Results](docs/how_to_execute_run.md) for instructions
