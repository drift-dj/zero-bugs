Welcome to **zero-bugs** (see what we did there?)... This is Zero's issue-reporting and QA nexus.  Use this space to report issues with your Zero.  

**How this works:**
- Create an issue in the Issues tab at the top of this page
- We will triage your issue and put it in the development pipeline
- As we work on your issue, we may have follow-up questions or ask you to execute a test-script to gather more details
- Once your issue has been resolved, we will tag it with a build number and ask you to re-test in that build
