Welcome to **zero-bugs** (see what we did there?)... This is Zero's issue-reporting and QA nexus.  Use this space to report issues with your Zero, and request new features.  

**How this works:**
- Create a bug or request a feature
- We will triage your issue and put it in the development pipeline
- As we work on your issue, we may have follow-up questions or ask you to execute a test-script to gather more details
- Once your issue has been resolved, we will tag it with a build number and ask you to test in that build
    - Download new Beta builds from the [Beta Testers](http://www.driftdj.com/beta-users.html) page

**How report a bug**
- Go to the Issues tab at the top of this page
- Click on [New Issue]
- Select Bug report
- Enter a description of your bug

**How to request a new feature**
- Go to the Issues tab at the top of this page
- Click on [New Issue]
- Select Feture Request
- Tell us a bit about what you'd like to see Zero do
